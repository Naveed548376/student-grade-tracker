# CodeAlfa Task 1 – Student Grade Tracker

A Java-based **Student Grade Tracker** developed as part of CodeAlfa Task 1.

The program allows users to enter student grades, manage the data, and generate a summary containing the average, highest, and lowest scores.

## 📌 Task Requirements

* Input and manage student grades
* Store student data using arrays or ArrayLists
* Calculate the average score
* Find the highest score
* Find the lowest score
* Display a summary report
* Use a console-based or GUI-based interface

## 🛠️ Technologies Used

* Java
* Arrays / ArrayLists
* Java Console
* Basic Java programming concepts

## 📊 Features

### Student Grade Management

The program allows the user to enter and manage grades for multiple students.

### Average Score

The program calculates the average grade of all students.

### Highest Score

The highest grade entered by the user is identified and displayed.

### Lowest Score

The lowest grade entered by the user is identified and displayed.

### Summary Report

A final report displays the students and their grades along with the calculated statistics.

## ▶️ How to Run

Make sure Java is installed on your system.

Compile the Java program:

```bash
javac "codeAlfa task 1.java"
```

Run the program:

```bash
java "codeAlfa task 1"
```

> If your source file has a different name or extension, replace the filename in the commands above.
